## Views on AI & Engineering

### Core Thesis
AI in software development is the next level of abstraction, following:
1. Punch cards → Assembler
2. Higher-level languages (functional, OOP)
3. Libraries and open source
4. **Now: Generative AI**

### Key Observations
- "We're used to trusting code we didn't write" (libraries, dependencies)
- "Once we trust AI-generated code, will we still read it?"
- "AI is like a junior developer who reads a lot but knows nothing about your product"
- Tests are the "ultimate lifeline" - the one thing that proves code works

### What He Builds For
- Codebases AI can reason about
- Documentation about the "why," not just the "what"
- Simple folder structures
- Commonly established best practices

### Pet Peeve
- People talking about "AI slop" as if it's permanent
- Missing the bigger picture of how AI will transform the profession
