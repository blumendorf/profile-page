# Create PR

Create a well-structured pull request with proper description.

## Steps
1. **Prepare branch**
   - Commit all changes
   - Push branch to remote
   - Verify branch is up to date with main
   - use semantic commit messages and branch names

2. **Set up PR**
   - Create PR with descriptive title

3. **Add a PR description**
   - use the template below

```
Template

[What and why—one or two sentences]

## Changes
- [Key change 1]
- [Key change 2]

```
